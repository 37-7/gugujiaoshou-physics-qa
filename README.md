# 物理系咕咕叫兽 · 好题分享评论区物理题集

> B 站 [@物理系咕咕叫兽](https://space.bilibili.com/) 「高中物理好题分享」系列视频评论区中的高质量物理问题，经整理、过滤、人工分类与公式重排后的**可检索可视化题集**。

**物理系咕咕叫兽**：麻省理工物理博士、复旦本科物理系第一、清华顶格降分，讲高考物理——「把普通学生教成所谓学神」。

---

## ✨ 功能特性

- **9 期合集**：覆盖第 1、2、3、5、6、7、8、9、10 期（第 4 期数据缺失），共 **238 个物理问题 / 905 条回复 / 235 张题图**
- **还原 B 站评论区结构**：楼主 + 楼中楼回复、头像、点赞数完整保留
- **逐条人工分类**：按高中物理模块归类（力学 / 曲线运动与机械能 / 动量 / 机械振动 / 光学 / 静电场 / 电路 / 磁场与电磁感应 / 交变电流 / 热学 / 原子与核 / 数学题 / 其他）
- **公式 LaTeX 化**：评论区里的纯文本公式（如 `v1方-v2方=2ax`、`P0V0+2P0V1`）已逐条转为规范的 LaTeX 并用 KaTeX 渲染
- **图片本地化**：B 站图片有防盗链，已全部下载压缩到本地，离线也能看图
- **收藏夹**：⭐ 收藏感兴趣的题目，一键只看收藏
- **已阅标记**：☑ 标记已读后自动隐藏，带历史记录可随时找回（本地持久化）
- **增强图片查看器**：点击放大，滚轮缩放、拖动平移、旋转、下载原图、键盘操作
- **关键词搜索** + **期数切换** + **模块导航**

## 📖 使用方法

### 本地查看
直接双击打开 `index.html`（或 `评论区物理题集_第1-10期合集.html`）即可，需保证 `_imgs/` 与 `assets/` 目录和 HTML 文件在同一目录下。

### 部署到 GitHub Pages
1. 把整个仓库推到 GitHub
2. `Settings → Pages → Source` 选择 `main` 分支根目录
3. 保存后即可通过 `https://<用户名>.github.io/<仓库名>/` 访问

## 🗂 目录结构

```
.
├── index.html                       # 主页（题集，自包含数据 + 逻辑）
├── assets/katex/                    # KaTeX 本地渲染资源（JS/CSS/字体）
├── _imgs/                           # 本地化的题图与头像（260 张题图 + 222 张头像）
└── README.md
```

> 注：仓库中的 `.py` 为生成脚本（数据清洗、分类、公式转换、图片下载），可复用于后续期数，不影响网页运行。
