# 物理系咕咕叫兽 · 好题分享评论区物理题集

> B 站 [@物理系咕咕叫兽](https://space.bilibili.com/) 「高中物理好题分享」系列视频评论区中的高质量物理问题，经整理、过滤、人工分类、公式重排后的**可检索可视化题集**。

**物理系咕咕叫兽**：麻省理工物理博士、复旦本科物理系第一、清华顶格降分，讲高考物理——「把普通学生教成所谓学神」。

---

## ✨ 功能特性

- **10 期合集**：覆盖第 1–10 期（含此前缺失的第 4 期），共 **255 个物理问题 / 990 条有效回复 / 252 张题图**
- **还原 B 站评论区结构**：楼主 + 楼中楼回复、头像、点赞数完整保留
- **逐条人工分类**：按高中物理模块归类（力学 / 曲线运动与机械能 / 动量 / 机械振动 / 光学 / 静电场 / 电路 / 磁场与电磁感应 / 交变电流 / 热学 / 原子与核 / 数学题 / 其他）
- **期数 × 知识点 双维度多选筛选**
  - 左侧栏可同时勾选多期（第 1–10 期）与多个知识点模块，取二者**交集**显示
  - 例：只看「第 1 期·光学」，或「第 5、6、10 期·力学基础 + 曲线运动与机械能」
  - 每轴「全选 / 清空」，一键「重置」
- **宽屏模式**：左侧筛选栏可折叠收起，收起后内容占满整屏
- **翻页浏览**：每页 12 条，带页码与上一页 / 下一页
- **常驻搜索框**：顶栏 `sticky` 常显，滚动时始终可见
  - **跨页搜索**：在所有筛选结果中检索，而非仅当前页
  - **范围选择**：默认「当前筛选范围」（随正在浏览的期数×知识点走），可切「全部范围」
  - **命中高亮**：匹配到的关键词以黄色背景高亮
- **阅读着色开关**：开启后
  - 所有拉丁字母（蓝）/ 数字（棕）着色
  - 定理定律名（基尔霍夫 / 欧姆 / 戴维南 / 柯尼希 … 等，已内置一批）着紫色
  - `@提及对象`着红色且不加超链接
  - UP 主本人发布的内容着金底并标「UP主」
  - KaTeX 公式、链接、题图不受影响
- **公式 LaTeX 化**：评论区里的纯文本公式已逐条转为规范 LaTeX 并用 KaTeX 渲染
- **图片本地化**：B 站图片有防盗链，已全部下载压缩到本地，离线也能看图
- **收藏夹**：⭐ 收藏感兴趣的题目，一键只看收藏
- **已阅标记**：☑ 标记已读后自动隐藏，带历史记录可随时找回（localStorage 本地持久化）
- **增强图片查看器**：点击放大，滚轮缩放、拖动平移、旋转、下载原图、键盘操作

## 🚀 在线预览

启用 GitHub Pages 后，访问仓库根目录的 `index.html` 即可（例如 `https://<用户名>.github.io/<仓库名>/`）。

## 📖 使用方法

### 本地查看
直接双击打开 `index.html` 即可，需保证 `_imgs/` 与 `assets/` 目录和 HTML 文件在同一目录下。

### 部署到 GitHub Pages
1. 把整个仓库推到 GitHub
2. `Settings → Pages → Source` 选择 `main` 分支根目录
3. 保存后即可通过 `https://<用户名>.github.io/<仓库名>/` 访问

## 🗂 目录结构

```
.
├── index.html                       # 主页（题集，自包含数据 + 逻辑）
├── assets/katex/                    # KaTeX 本地渲染资源（JS/CSS/字体）
├── _imgs/                           # 本地化的题图（252 张）与头像
├── gen_multi_episode.py             # 主生成器（数据清洗 + 分类 + 拼接）
├── new_template.html                # 页面模板（经 splice.py 注入生成器）
├── splice.py                        # 模板注入脚本
├── formula.py                       # 公式 LaTeX 转换
├── download_images.py               # 题图本地化脚本
├── download_faces.py               # 头像本地化脚本
├── README.md
├── LICENSE
├── .gitignore
└── .gitattributes                   # 换行符 LF 规范化
```

> 注：`.py` 为生成脚本（数据清洗、分类、公式转换、图片下载），可复用于后续期数，不影响网页运行；`.workbuddy/` 与临时文件已在 `.gitignore` 中排除，不会进入仓库。
